# Expérience de jeu autonome

## Statut et autorité

Ce document définit le contrat d'expérience commun aux jeux d'enquête Molly's Files. Les règles exécutables sont décrites dans `engine/autonomous_gameplay.json`. Chaque univers doit fournir son contrat spécifique validé par `schemas/gameplay_contract.schema.json`.

Un jeu ne peut pas être déclaré prêt à vendre s'il nécessite qu'une personne connaisse la solution, distribue manuellement les révélations au bon moment ou improvise pour débloquer les joueurs.

## Promesse client

L'organisateur prépare matériellement la soirée, puis joue comme les autres. Il ne connaît ni le coupable, ni la méthode, ni la solution avant la révélation finale.

Le jeu avance grâce à :

1. des dossiers individuels classés par acte ;
2. des enveloppes collectives numérotées ;
3. des obligations de révélation écrites sur les fiches ;
4. un compagnon numérique de progression ;
5. un parcours hors ligne de secours ;
6. une échelle d'indices progressive.

Le téléphone rythme et débloque la partie, mais les échanges, les mensonges, les documents et les accusations restent au centre de l'expérience.

## Contenu remis à l'organisateur

### Pack sans spoiler

L'organisateur peut lire librement :

- la checklist de préparation ;
- les descriptions publiques des personnages ;
- le guide d'attribution des rôles ;
- les invitations ;
- le plan d'installation ;
- les règles à lire à voix haute ;
- le guide « Que faire maintenant ? » ;
- la procédure hors ligne.

### Matériel individuel

Chaque joueur reçoit :

- une fiche de départ ;
- ses informations des actes II et III ;
- ses objectifs personnels ;
- ses secrets ;
- ses révélations conditionnelles ;
- au moins une révélation obligatoire ;
- éventuellement un document ou objet personnel.

### Matériel collectif

Le jeu comprend :

- trois enveloppes collectives ;
- une feuille de chronologie ;
- les documents d'enquête ;
- les bulletins d'accusation ;
- une solution finale scellée ;
- une version écrite de la révélation ;
- un script prévu pour une future version audio.

## Préparation

La préparation cible doit rester inférieure à 30 minutes hors impression.

L'organisateur :

1. confirme l'attribution des rôles ;
2. envoie les invitations ;
3. imprime ou distribue les dossiers ;
4. prépare les enveloppes dans l'ordre indiqué ;
5. place la chronologie et les bulletins ;
6. rend accessible le QR code de progression.

Les costumes, la musique et la décoration sont facultatifs. Leur absence ne doit jamais dégrader la résolution.

## Règles joueurs

### Incarner sans obligation théâtrale

Les joueurs parlent à la première personne à partir des faits fournis. Aucun accent, costume ou talent d'improvisation n'est requis.

### Mentir loyalement

Un joueur peut mentir, esquiver, minimiser, protéger un secret et accuser quelqu'un. Il ne peut pas inventer un nouvel alibi, un événement, une preuve ou une relation absente de sa fiche.

### Valeur des documents

Un document de jeu fait foi, sauf s'il est explicitement qualifié de falsifié, incomplet ou douteux. Une déclaration de personnage peut être mensongère.

### Circulation des preuves

Une preuve collective découverte ne peut être détruite ni cachée définitivement. Un personnage peut tenter d'en contrôler l'interprétation, pas empêcher son existence dans le jeu.

### Jeu du coupable

Le coupable connaît sa responsabilité dès le début dans le mode standard. Il peut créer un doute raisonnable mais ne peut pas :

- contredire un fait immuable ;
- bloquer un indice obligatoire ;
- refuser une révélation imposée ;
- inventer une autre chronologie ;
- rendre l'enquête insoluble.

## Classes d'information

Chaque information d'une fiche appartient à une classe explicite.

### Libre

Le joueur choisit quand et comment la révéler.

### Conditionnelle

Le joueur doit la révéler lorsque le déclencheur écrit se produit. Chaque déclencheur possède un mécanisme de secours si la situation n'arrive pas spontanément.

### Obligatoire

Le joueur doit la révéler avant la fin de l'acte indiqué. Le compagnon numérique rappelle les échéances sans dévoiler la solution.

## Boucle d'un acte

Chaque acte suit cinq phases.

1. **Lecture privée** : chacun découvre ses nouvelles informations.
2. **Enquête libre** : interrogatoires, comparaison des versions et examen des documents.
3. **Objectifs personnels** : les joueurs agissent pour protéger, découvrir ou obtenir quelque chose.
4. **Question collective** : le groupe synthétise ce qu'il croit avoir compris.
5. **Déverrouillage** : l'enveloppe ou la révélation suivante devient accessible.

La réponse collective n'a pas besoin d'être juste. Elle oblige le groupe à construire une hypothèse et permet au système de vérifier que l'étape a été discutée.

## Compagnon numérique

L'interface collective doit rester simple et utilisable depuis un seul téléphone.

Elle affiche uniquement :

- l'acte en cours ;
- le temps conseillé ;
- les rappels de révélations obligatoires ;
- la question collective ;
- le bouton de progression ;
- les aides ;
- le bouton « Que faire maintenant ? » ;
- la solution, uniquement après les accusations.

Le minuteur peut être mis en pause. Le jeu doit également pouvoir être terminé sans connexion grâce aux enveloppes et au guide hors ligne.

## Progression autonome

Les déclencheurs admis sont :

- temps écoulé ;
- réponse à la question collective ;
- événement explicitement indiqué sur une fiche ;
- confirmation manuelle du groupe.

Toute révélation indispensable doit posséder :

- un moment prévu ;
- une personne ou une enveloppe responsable ;
- une échéance ;
- un secours automatique ;
- une trace dans le contrat de l'univers.

Aucune progression ne doit dépendre de l'intuition de l'organisateur.

## Système anti-blocage

Quatre niveaux d'aide sont disponibles.

### Niveau 1 — Orientation

Une question recentre le groupe sans donner la réponse.

### Niveau 2 — Comparaison

Le système indique quels témoignages ou documents doivent être rapprochés.

### Niveau 3 — Déduction explicite

Une conclusion importante est révélée.

### Niveau 4 — Indice de déblocage

Une preuve complémentaire est introduite pour garantir la fin de partie.

Les niveaux 2 à 4 peuvent réduire le score, mais aucune aide ne doit humilier les joueurs ou leur retirer la possibilité de comprendre la solution finale.

## Accusation finale

La solution reste verrouillée tant que les bulletins ne sont pas déposés.

Deux modes sont prévus :

- accusation individuelle ;
- accusation collective.

Une accusation complète répond à cinq questions :

1. Qui est responsable ?
2. Quel est son mobile ?
3. Quelle méthode a été utilisée ?
4. Quand l'action décisive a-t-elle eu lieu ?
5. Quelles sont les trois preuves principales ?

## Révélation

La solution est présentée dans cet ordre :

1. démontage de la fausse impossibilité ;
2. moment réel de l'action ;
3. méthode ;
4. mobile ;
5. mensonges du coupable ;
6. chaîne de preuves ;
7. confession finale ;
8. épilogue de chaque personnage.

Une version écrite est obligatoire. Un script audio peut être généré, mais ne constitue pas le seul moyen d'obtenir la solution.

## Conditions de victoire

### Enquêteurs

Victoire complète : coupable, méthode et mobile corrects.

Victoire partielle : coupable correctement identifié.

### Coupable

Victoire si moins de la moitié des joueurs l'accusent correctement.

### Objectifs personnels

Chaque personnage possède des objectifs secondaires comptés séparément afin qu'un joueur conserve une trajectoire intéressante même s'il ne résout pas le meurtre.

## Absence de dernière minute

Les rôles optionnels sont retirés en premier. Toute information utile qu'ils détenaient est transférée vers :

- un document collectif ;
- un autre personnage ;
- une révélation numérique.

Chaque univers déclare son nombre minimal de joueurs. Un mode dégradé ne peut être vendu comme équivalent au mode standard sans test dédié.

## Critères de validation

Avant commercialisation, le jeu doit prouver que :

- l'organisateur ne reçoit aucun spoiler ;
- l'organisateur n'a aucune tâche spéciale pendant la partie ;
- chaque acte possède une question et un déverrouillage ;
- chaque information obligatoire a une échéance ;
- chaque déclencheur conditionnel a un secours ;
- les quatre niveaux d'aide sont disponibles ;
- le parcours hors ligne aboutit à la même solution ;
- le coupable respecte un contrat de jeu loyal ;
- les accusations précèdent toujours la solution ;
- la partie se termine sans intervention extérieure ;
- au moins trois tests complets ont validé la progression.

## Application au Palace des Ombres

Le contrat spécifique du premier univers se trouve dans `universes/palace_1930_gameplay.json`.

Format de référence :

- 6 ou 8 joueurs ;
- trois actes ;
- environ 2 h 30 ;
- préparation sans spoiler ;
- organisateur-joueur ;
- enveloppes physiques ;
- compagnon numérique collectif ;
- solution écrite et script audio ;
- mode hors ligne complet.
